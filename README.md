# Настройка компьютера

Этот репозиторий — личная, воспроизводимая база настроек рабочего компьютера: программы, конфигурационные файлы, инструкции и небольшие скрипты для установки.

## Что здесь хранится

- список нужных приложений и сервисов;
- конфигурации редакторов, терминала, Git и других программ;
- инструкции по настройке системы, клавиатуры и рабочего окружения;
- скрипты, которые безопасно автоматизируют повторяющиеся шаги;
- заметки о ручных действиях, которые нельзя или не стоит автоматизировать.

## Нужные программы

### Codex

Установите Codex для работы с этим репозиторием. Актуальная инструкция доступна
в [официальной документации Codex CLI](https://learn.chatgpt.com/docs/codex/cli).

## Предлагаемая структура

```text
apps/       # программы, расширения и способы их установки
configs/    # конфигурационные файлы по приложениям
keyboard/   # раскладки, сочетания клавиш и настройка устройств ввода
scripts/    # скрипты установки и настройки
docs/       # пошаговые инструкции и заметки
```

Создавайте папки по мере появления материалов — не нужно поддерживать пустую структуру.

## Как использовать

1. После настройки программы добавьте сюда её конфигурацию или инструкцию по установке.
2. Указывайте ОС, версии программ и команды, если они важны.
3. Перед запуском любого скрипта просмотрите его содержимое и запускайте только подходящие для текущей системы части.
4. Не добавляйте пароли, токены, приватные ключи и другие секреты. Для них используйте менеджер секретов или локальные файлы, исключённые через `.gitignore`.

## Первая настройка на новом компьютере

Порядок будет пополняться по мере наполнения репозитория. Обычно он такой: установить базовые программы, применить конфигурации, настроить клавиатуру и проверить рабочие инструменты.

## Принципы

- Документировать всё, что пришлось настраивать вручную.
- Делать инструкции короткими и проверяемыми.
- Предпочитать идемпотентные скрипты: повторный запуск не должен ломать систему.
- Хранить в Git только то, чем безопасно делиться между своими устройствами.
