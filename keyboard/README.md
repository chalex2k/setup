# Клавиатура

## Русская раскладка с переставленными `б`, `ю`, `,`, `.` и `\\`

Файл [custom](custom) содержит XKB-вариант `custom(basic)` для Ubuntu:

- `б` → `,`;
- `ю` → `.`;
- `.` → `б`;
- `\\` → `ю`.

Установка:

```bash
sudo install -m 644 keyboard/custom /usr/share/X11/xkb/symbols/custom
```

Затем откройте **Настройки → Клавиатура → Источники ввода**, добавьте русский
язык и выберите вариант **Russian (custom)**. Если вариант не появился сразу,
выйдите из сеанса и войдите снова (либо перезагрузите компьютер).

## Caps Lock и Ctrl

Нужно настроить клавиатуру так, чтобы клавиши `Ctrl` и `Caps Lock` были поменяны местами.

Альтернативный, предпочтительный вариант для Ubuntu: при удержании `Caps Lock` работает как `Ctrl`, а при одиночном нажатии сохраняет обычное поведение `Caps Lock`.

Способ реализации будет добавлен позже, когда удастся вспомнить или заново выбрать подходящий вариант.

## Английская раскладка

В настройках системы включить раскладку `Colemak` для английского языка вместо стандартной `QWERTY`.
